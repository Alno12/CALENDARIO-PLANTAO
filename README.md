# Escala · Gestor de plantões

App para organizar plantões, controlar pagamentos e acompanhar ganhos.
Funciona offline e pode ser instalado na tela de início do celular.

## Como publicar (GitHub Pages)

1. Envie todos estes arquivos para a raiz do repositório
   (Add file → Upload files → arraste tudo → Commit changes).
2. No repositório: Settings → Pages → Source: "Deploy from a branch"
   → Branch: `main` / pasta `/ (root)` → Save.
3. Aguarde 1–2 minutos. O endereço fica:
   `https://SEU-USUARIO.github.io/NOME-DO-REPO/`

## Como instalar no iPhone

1. Abra o endereço acima no **Safari** (com internet, na primeira vez).
2. Toque em **Compartilhar** (quadrado com seta) → **Adicionar à Tela de Início**.
3. Pronto: abre em tela cheia, com ícone próprio, e funciona **sem internet**.

## Seus dados

- Tudo fica salvo **no próprio aparelho** — nada vai para a nuvem.
- Faça backups de vez em quando: aba **Ajustes → Exportar backup completo**.
- Para atualizar o app no futuro, substitua os arquivos no repositório e
  mude a versão no início do `sw.js` (ex.: `escala-v1` → `escala-v2`).
